# Contributing

Use Node 24 LTS and `npm ci`. Install Playwright browsers separately, then run the README's typecheck, lint, unit, build, E2E, packaging and production consumer commands. Preserve strict UTF-8/source bytes, explicit unsupported behavior, half-open millisecond intervals, complete mapping accounting and decision invalidation.

Use only your own or suitably licensed synthetic fixtures in issues/PRs. Never attach client subtitles, account secrets, video or browser profiles. Add an independent expected manifest for a regression; do not generate expectations from the algorithm under test. Explain observed behavior, input subset and validation. Improvements to professional-language workflow need an actual translator pilot before claiming time saved or accuracy gains.
