# Small comparative handoff

Primary descriptions checked on 2026-10-12 (Asia/Almaty): [Subtitle Edit](https://github.com/SubtitleEdit/subtitleedit) v5.2.0 describes an offline editor with optional online services; [SubtitleQA](https://github.com/romanbean/SubtitleQA/tree/e9fddd876878e1fe16277511a608ba3fc3088454) describes bilingual editing, comfort/CPS and CSV reports; [Subsmith](https://github.com/Skytuhua/subsmith/tree/c930c921c43393cc398e2df60015e730dc74b397) describes client-side timing/encoding repair, lint, conversion and undo; [Subtitle Diff](https://www.allsubconverter.com/subtitle-diff/) describes timecode-based alignment and diff reports (site does not declare an engine version). Local editing, privacy, lint and diff are established capabilities.

One actual core comparison used the closest small bilingual matcher, SubtitleQA at commit `e9fddd876878e1fe16277511a608ba3fc3088454`. Its original parser and matcher function ASTs were executed verbatim with actual chardet, re and difflib; no matching code was rewritten or stubbed. The Streamlit GUI and the complete product were not exercised. The original script stayed outside this repository; no competitor code was reused or redistributed. Its parser/matcher read our own [English](../fixtures/comparison-source.srt) and [Spanish](../fixtures/comparison-translation.srt) pair: three source cues, one valid merged translation of the first two, and an uncovered final source interval.

The returned SubtitleQA match contained the first two English cues, with text-similarity ratio about 0.349. Its returned list contained no explicit unmatched third-source record. CueReviewKit's same pair produced an `n:1` group for source ordinals 0/1 and an unmatched group for ordinal 2, with 0/1000 ms coverage evidence. This is an observed **function-output comparison**, not a claim that SubtitleQA has no possible workflow for the remaining interval. [Recorded competitor result](qa/subtitleqa-comparison.json) · [CueReviewKit result](qa/cuereview-comparison.json).

CueReviewKit additionally proves its own version-bound approval and clean-session package round trip in unit/E2E/consumer gates. Those tests do not establish feature absence elsewhere or demand from translators. No time-saving, precision, testimonials or semantic-accuracy measurements are claimed. An external pilot is still needed.

The [Aegisub short-interval issue #565](https://github.com/TypesettingTools/aegisub/issues/565) is a concrete user report about zero and very short intervals; replies point to selection scripting and CPS. It motivates inspecting timing evidence, not a claim that existing tools cannot handle it.
